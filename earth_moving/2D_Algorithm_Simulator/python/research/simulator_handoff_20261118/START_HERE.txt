Critical interpretation
Mouse edits and parameter changes rebuild the environment. After an action,
target searches are selective, but propagation, heat and staging are rebuilt
globally. The UI ALSO performs a fresh calculation for verification and falls
back to it if a mismatch occurs. UI elapsed time is therefore not a selective
update benchmark. Search counts are not speedup measurements. Regression tests
cover finite cases, not a proof of universal equivalence or optimality.

Controls and highlights
Move piles/target with the mouse; T/H select target/staging; Enter executes;
U undo; S save; L latest save; F1/F2 user/math guides. In Move piles mode an
empty click clears the preview. Display groups heat, paths, arrows, scope,
straight scope lines, update overlays and optional unchanged cells.
E pink = emptied; D cyan = changed occupied; R yellow = dependency affected;
S purple = spill; U green border = optional unchanged. Green filled piles are
material markers, not evidence of being updated. Updates ON hides U by default.
Source saves: thesis/seminar/interactive_saved. Preserve the user's saved scenes.
