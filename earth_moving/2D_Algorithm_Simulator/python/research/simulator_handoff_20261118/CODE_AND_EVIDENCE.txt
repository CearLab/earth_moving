Algorithm qualifications
Heat is a directional planning score, not material mass or predicted mission
time. Search is reward-directed and should not be described as globally optimal.
The current spill approximation uses sampled spline curvature and load; it is
not a calibrated physical model. Review its sample-count dependence, threshold,
rounding/correction behavior and unused capacity argument before interpreting
parameter sweeps physically. Alternative models require consistent prediction,
execution and accounting contracts, not merely replacing a plotted curve.
